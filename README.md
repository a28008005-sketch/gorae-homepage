# 🐋 고래영어 원생관리 홈페이지

노션 **[프리미엄] 고래영어 학생관리** 페이지의 구조를 그대로 옮긴, 학원 자체 원생관리형 웹 홈페이지입니다.
서버·데이터베이스·회원가입 없이 **브라우저만 있으면 바로 쓸 수 있습니다.**

---

## 1. 바로 사용하기

### 방법 A — 파일을 그대로 열기 (가장 간단)
`index.html` 파일을 더블클릭하면 바로 열립니다. 인터넷 연결도 필요 없습니다.

### 방법 B — GitHub Pages로 올리기 (학부모 공유 링크까지 쓰려면 권장)
1. 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main` (또는 이 브랜치) / `root` 선택 후 저장
3. 몇 분 뒤 `https://<아이디>.github.io/gorae-homepage/` 주소로 접속

> 학부모 공유 링크는 **접속 중인 주소를 기준으로** 만들어집니다.
> 파일을 직접 열어(A) 만든 링크는 그 컴퓨터에서만 열리므로, 학부모님께 보낼 링크는 반드시 B 방식의 주소에서 만들어 주세요.

## 3. 처음 시작하는 순서

1. **설정 · 백업 → 학원 정보**에서 학원명·연락처·수업 시간대를 입력합니다.
2. **학생 명부 → + 학생 등록**으로 원생을 등록합니다. (요일·시간·좌석을 함께 넣어두면 이후가 편합니다)
3. 매일 수업 때 **출결 · 일일학습**에서 체크합니다. 입력하는 즉시 저장됩니다.
4. 수업 중에는 **순회 점검**의 빠른 기록 카드로 학생 상태를 남깁니다.
5. 월말에 **학부모 공유**에서 리포트를 만들어 카카오톡·문자로 링크를 보냅니다.

> 기능을 먼저 둘러보고 싶다면 **설정 · 백업 → 예시 데이터 넣기**를 눌러보세요.
> 예시 학생 8명과 최근 3주치 출결이 채워집니다.

## 4. 데이터가 저장되는 곳 — 꼭 읽어주세요

- 모든 기록은 **사용하는 브라우저 안(localStorage)에만** 저장됩니다. 외부 서버로 전송되지 않습니다.
- 그래서 다음 경우에는 기록이 사라집니다.
  - 브라우저 데이터(쿠키·사이트 데이터)를 삭제한 경우
  - 다른 컴퓨터·다른 브라우저에서 접속한 경우
  - 시크릿 모드로 사용한 경우
- **주 1회 정도 [설정 · 백업 → 백업 파일 내보내기]로 JSON 파일을 내려받아 두세요.**
  다른 기기에서는 그 파일을 [백업 파일 불러오기]로 넣으면 그대로 이어서 쓸 수 있습니다.

## 5. 학부모 공유 링크에 대해

- 링크 안에는 **학생 이름·학년·출결 기록·선생님 코멘트만** 담깁니다. 학생/학부모 연락처는 포함되지 않습니다.
- 링크를 아는 사람은 누구나 열람할 수 있으므로 **해당 학부모님께만** 전달해 주세요.
- 리포트는 생성 시점의 기록을 담은 사진 같은 것입니다. 이후 출결이 바뀌어도 이미 보낸 링크는 갱신되지 않으니, 새 기간의 리포트는 새로 만들어 보내면 됩니다.
- 기간이 길면 링크가 길어집니다. 한 달 단위로 끊어 보내시는 것을 권합니다.

## 6. 기술 메모

- 빌드 도구·프레임워크·외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 작성했습니다.
- `assets/js/util.js` (공통 유틸) → `store.js` (데이터) → `ui.js` (공통 UI) → `views/*.js` (화면) → `app.js` (해시 라우터) 순으로 읽힙니다.
- 화면을 추가하려면 `assets/js/views/`에 `title() / sub() / render(el)`를 가진 모듈을 만들어 `Views.<이름>`으로 등록하고, `index.html`의 스크립트와 좌측 메뉴에 `#/<이름>` 링크를 넣으면 됩니다.
