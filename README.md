# 🐋 고래영어

고래영어학원 초전캠퍼스의 홈페이지와 원생관리 대시보드 원본입니다.

---

## 무엇이 들어 있나

| 폴더 | 내용 |
|---|---|
| `site/` | 소개 홈페이지 (`index.html` 한 파일에 스타일·사진이 모두 들어있습니다) |
| `workers/` | 원장님용 대시보드 — Cloudflare Workers에 올라갑니다 |
| `tools/blog/` | 노션 글을 읽어 블로그 화면을 만드는 프로그램 |

원생 정보는 **이 저장소에 없습니다.** 학생 데이터는 전부 노션에 있고,
대시보드는 그것을 읽어와 보여주기만 합니다.

---

## 1. 대시보드 (원장님용)

```
https://hello-world.a28008005.workers.dev/dashboard
```

처음 열면 **비밀번호**를 한 번 물어봅니다. 브라우저가 기억하므로 다음부터는
바로 들어갑니다.

### 매일 쓰는 것

- **출석 현황** — 학생 이름 옆 `출석` / `결석` 버튼을 누르면 노션에 바로 저장됩니다.
  잘못 눌러도 다시 누르면 고쳐집니다
- **월간 캘린더** — 날짜마다 그날 출석(초록)·결석(빨강) 인원이 보입니다
- **과제** — 아이들의 보카 학습 수행률·성취률이 보입니다

### 가끔 쓰는 것

- **학생 목록** — 원생 명단과 **학습코드**. 코드 없는 학생은
  `코드 없는 학생에게 발급` 버튼으로 한 번에 만들 수 있습니다
- **영자신문** — 워크시트 PDF를 눌러 바로 엽니다
- 그 밖에 상담일지·결제·수업일지·알림·자료실·도서대여·업무메모

### 대시보드를 고쳤을 때

Cloudflare 편집기에 코드를 붙여넣고 **Deploy**를 눌러야 반영됩니다.

```
https://dash.cloudflare.com/?to=/:account/workers/services/edit/hello-world/production
```

## 2. 학생용 앱

| 앱 | 주소 | 하는 일 |
|---|---|---|
| 고래 데일리 듣기 | `a28008005-sketch.github.io/dailytest/` | 레벨별 듣기 연습 |
| 웨일리 보카 | `a28008005-sketch.github.io/dailytest/voca/` | 6레벨 720일차 단어·문장 |

아이들은 **학습코드**로 들어갑니다. 코드가 곧 신분이라 학원 태블릿이든 집
휴대폰이든 **하던 데서 이어서** 합니다. 하루치를 끝내면 성적이 대시보드
`과제` 탭에 자동으로 쌓입니다.

앱 파일은 `dailytest` 저장소에 있습니다.

## 3. 홈페이지 발행

홈페이지는 **"발행"이라고 말했을 때만** 올라갑니다. 자동 배포는 모두 꺼져
있어서, 이 저장소에 파일을 올리는 것만으로는 홈페이지가 바뀌지 않습니다.

발행하면 `gorae-site` 저장소로 옮겨 담고, Vercel이 받아서 올립니다.
