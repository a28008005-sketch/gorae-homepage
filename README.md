# 🐋 고래영어 원생관리 홈페이지

노션 **[프리미엄] 고래영어 학생관리** 페이지의 구조를 그대로 옮긴, 학원 자체 원생관리형 웹 홈페이지입니다.
서버·데이터베이스·회원가입 없이 **브라우저만 있으면 바로 쓸 수 있습니다.**

---

## 1. 바로 사용하기

### 방법 A — 파일을 그대로 열기 (가장 간단)
`index.html` 파일을 더블클릭하면 바로 열립니다. 인터넷 연결도 필요 없습니다.

파일 하나로 들고 다니고 싶다면 [`dist/고래영어-원생관리.html`](dist/) 을 받으세요.
CSS·JS가 모두 안에 들어 있어 그 파일 하나만 있으면 어디서든 열립니다. 다시 만들 때는:

```
node tools/bundle.js            # dist/고래영어-원생관리.html
node tools/bundle.js --demo     # 예시 데이터가 들어간 미리보기용
```

### 방법 B — 홈페이지 주소로 올리기 (학부모 공유 링크까지 쓰려면 권장)

이 홈페이지의 주소는 **https://whalejinju.kr** 입니다. 저장소 맨 위의 [`CNAME`](CNAME) 파일이
GitHub Pages에 이 주소를 알려주는 역할을 합니다. 지우지 말아 주세요.

**1) GitHub 쪽 설정**
1. 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 기본 브랜치 / `root` 선택 후 저장
3. Custom domain 칸에 `whalejinju.kr` 이 들어가 있는지 확인 (`CNAME` 파일이 있으면 자동으로 채워집니다)
4. DNS 확인이 끝나면 **Enforce HTTPS**에 체크

**2) 가비아 DNS 설정** — My가비아 → 도메인 → **DNS 관리툴** → DNS 설정 → 레코드 수정

| 타입 | 호스트 | 값 | 비고 |
|---|---|---|---|
| A | @ | `185.199.108.153` | GitHub Pages |
| A | @ | `185.199.109.153` | |
| A | @ | `185.199.110.153` | |
| A | @ | `185.199.111.153` | |
| CNAME | www | `a28008005-sketch.github.io.` | www 로 들어와도 열리도록 |

네임서버는 가비아 기본값(`ns.gabia.co.kr` 등)을 그대로 두고 위 레코드만 넣으면 됩니다.
DNS는 반영까지 보통 10분~1시간, 길면 하루쯤 걸립니다. 그동안 Pages 설정 화면에 노란 경고가 떠도 정상입니다.

> **비공개 저장소 주의** — 이 저장소는 현재 비공개(private)입니다.
> GitHub Pages는 비공개 저장소에서는 유료 요금제(GitHub Pro 이상)에서만 켜집니다.
> 무료 요금제라면 저장소를 공개로 바꾸거나, 요금제를 올려야 `whalejinju.kr` 이 열립니다.
> (저장소를 공개해도 학생 기록은 브라우저에만 저장되므로 함께 공개되지 않습니다. 공개되는 것은 프로그램 코드뿐입니다.)

> 학부모 공유 링크는 **접속 중인 주소를 기준으로** 만들어집니다.
> 파일을 직접 열어(A) 만든 링크는 그 컴퓨터에서만 열리므로, 학부모님께 보낼 링크는 반드시
> `https://whalejinju.kr` 로 접속한 뒤 만들어 주세요.

## 3. 처음 시작하는 순서

1. **설정 · 백업 → 학원 정보**에서 학원명·연락처·수업 시간대를 입력합니다.
2. **학생 명부 → + 학생 등록**으로 원생을 등록합니다.
3. **반 · 시간표**에서 반을 만들고 학생을 배정합니다. 반에 요일·시간을 넣어두면 학생은 반 시간표를 따릅니다.
4. 매일 수업 때 **출결 · 일일학습**에서 출결과 수업 태도를 함께 체크합니다. 입력하는 즉시 저장됩니다.
5. 월초에 **수강료 납부 → 청구서 일괄 생성**을 누르고, 입금이 확인되면 [납부 처리]를 눌러 둡니다.
6. 월말에 **학부모 공유**에서 리포트를 만들어 카카오톡·문자로 링크를 보냅니다.

> 기능을 먼저 둘러보고 싶다면 **설정 · 백업 → 예시 데이터 넣기**를 눌러보세요.
> 예시 학생 8명과 최근 3주치 출결이 채워집니다.

## 4. 두 가지 사용 모드

| | 이 기기 저장 (기본) | 클라우드 공유 |
|---|---|---|
| 설치 | 없음 | Supabase 프로젝트 1회 설정 (약 30분) |
| 로그인 | 없음 | 선생님별 계정 |
| 여러 선생님 | ✗ 각자 따로 | ✓ 같은 명부·출결을 함께 |
| 인터넷 | 없어도 됨 | 끊겨도 입력 가능, 연결되면 자동 전송 |
| 비용 | 없음 | 무료 요금제로 충분 |

혼자 쓰시면 **이 기기 저장**으로 충분합니다. 선생님이 늘어 각자 기기에서 입력해야 할 때
**설정 · 백업 → 여러 기기에서 함께 쓰기**에서 클라우드를 연결하시면 됩니다.
쓰시던 기록은 **[전체 올리기]** 한 번으로 그대로 옮겨집니다.

설정 방법은 [`docs/서버형-설치안내.md`](docs/서버형-설치안내.md)에 단계별로 적어두었습니다.

### 클라우드로 옮긴 뒤 동작
- 입력은 **즉시 그 기기에 저장**되고 1초쯤 뒤 클라우드로 올라갑니다.
- 다른 선생님의 입력은 **15초마다** 내려옵니다. 오른쪽 위 상태 칩에서 `지금 동기화`로 즉시 받을 수도 있습니다.
- 인터넷이 끊기면 상태 칩이 `오프라인 · 대기중 (N)`으로 바뀌고, 입력은 계속 됩니다. 연결되면 밀린 기록이 자동 전송됩니다.
- 같은 기록을 두 분이 동시에 고치면 **나중에 저장한 쪽이 남습니다.**
- 학부모 공유 리포트와 납부 확인서는 **로그인 없이** 열립니다.

## 5. 데이터가 저장되는 곳 — 꼭 읽어주세요

아래는 **이 기기 저장 모드** 기준입니다. 클라우드를 연결하면 기록이 양쪽에 저장되어 기기 한 대가 고장 나도 남습니다.

- 모든 기록은 **사용하는 브라우저 안(localStorage)에만** 저장됩니다. 외부 서버로 전송되지 않습니다.
- 그래서 다음 경우에는 기록이 사라집니다.
  - 브라우저 데이터(쿠키·사이트 데이터)를 삭제한 경우
  - 다른 컴퓨터·다른 브라우저에서 접속한 경우
  - 시크릿 모드로 사용한 경우
- **주 1회 정도 [설정 · 백업 → 백업 파일 내보내기]로 JSON 파일을 내려받아 두세요.**
  다른 기기에서는 그 파일을 [백업 파일 불러오기]로 넣으면 그대로 이어서 쓸 수 있습니다.

## 6. 반과 수업 태도

### 반(클래스)
- **반 · 시간표**에서 반을 만들고 요일·시간·담당 선생님·정원·색상을 정합니다.
- 학생을 반에 배정하면 그 학생의 수업 요일과 시간은 **반 시간표를 따릅니다.** 반을 옮기면 출결 대상도 함께 바뀝니다.
- 반에 넣지 않은 학생은 학생 개인의 요일·시간으로 출결이 잡힙니다. 개인 과외처럼 시간이 따로인 학생을 위한 것입니다.
- 이미 학생별로 요일·시간을 넣어 쓰고 계셨다면 **[기존 시간표로 반 만들기]** 버튼이 같은 요일·시간끼리 묶어 반을 자동으로 만들어 줍니다. 만든 뒤 반 이름만 바꾸시면 됩니다.
- 반을 삭제해도 학생과 출결·수강료 기록은 남고, 소속만 미배정으로 돌아갑니다.

### 수업 태도
예전의 순회 점검 기록이 일일학습 안으로 들어왔습니다. 출결 체크하는 그 줄에서 바로 태도를 누르면 됩니다.

`🟢 집중` · `💤 졸음` · `🏃 이탈/부재` · `📱 휴대폰 사용` · `💬 잡담/소란`

집중을 뺀 나머지가 **태도 주의**로 집계되어 통계와 학생 상세에 나옵니다.
기존에 쌓아둔 순회 점검 기록은 프로그램을 열 때 **그날의 일일학습 기록 안으로 자동으로 옮겨집니다.** 따로 하실 일은 없습니다.

## 7. 숙제 · 단어 학습 · 도서 대여

### 숙제 관리
- 반을 골라 숙제를 내면 **소속 학생 전원에게 제출 칸**이 만들어집니다. 반을 고르지 않으면 등록생 전체가 대상입니다.
- [제출 체크]에서 학생별로 `미제출 / 제출 / 확인`을 누르고 점수·메모를 남깁니다. [전원 제출 처리]로 한 번에도 됩니다.
- 카드에 제출률과 **미제출 학생 이름**이 바로 뜹니다. 대시보드에서도 진행 중인 숙제의 제출률을 봅니다.
- 출결 화면의 `숙제` 체크는 그날 숙제를 해왔는지 보는 **일일 체크**이고, 이 화면은 과제 하나를 끝까지 추적하는 용도입니다.

### 단어 학습 (앱 연동)
만들고 계신 단어학습앱의 결과를 받아 쌓습니다. 넣는 방법은 세 가지입니다.

1. **링크** — 앱이 `#/import?d=<base64 JSON>` 주소를 열면 미리보기와 함께 들어옵니다
2. **파일** — 앱에서 내보낸 `.json` / `.csv`를 [기록 가져오기]로 선택
3. **붙여넣기** — 창에 그대로 붙여넣기

학생은 **학생 코드**(4자리)나 이름으로 찾습니다. 코드는 [학생 코드] 화면에서 한 번에 발급하고 CSV로 내려받아 앱에 넣으시면 됩니다.
같은 `sessionId`가 다시 들어오면 덮어쓰므로 **두 번 보내도 기록이 중복되지 않습니다.**

형식과 예제 코드는 [`docs/단어학습앱-연동.md`](docs/단어학습앱-연동.md)에 정리했습니다.

### 도서 대여
- **[CSV 일괄 등록]**으로 도서 목록을 한 번에 넣습니다. 라이브러리 3000처럼 권수가 많을 때 씁니다. 양식은 창 안에서 내려받을 수 있습니다.
- 화면 위 **청구기호 칸에 번호를 넣고 Enter**를 치면, 대출 가능한 책은 대여 창이, 대출 중인 책은 반납 확인이 바로 뜹니다. 바코드 스캐너를 쓰신다면 스캐너가 Enter까지 입력하므로 그대로 동작합니다.
- 반납 예정일은 기본 7일이며 대여할 때 바꿀 수 있습니다. 기한이 지나면 **연체**로 잡혀 화면 위와 대시보드에 뜹니다.
- 학생 상세에서 그 학생의 누적 대출 권수와 지금 빌린 책을 봅니다.

### 도서 워크시트
책을 빌려줄 때 **독후활동지가 함께 나옵니다.** 대여 창의 `워크시트 같이 뽑기`가 기본으로 켜져 있습니다.

무엇이 나오는지는 그 책에 등록해 둔 것에 따라 달라집니다.

| 등록한 것 | 나오는 것 |
|---|---|
| 워크시트 링크 (PDF·구글드라이브 등) | 그 링크를 새 창으로 엽니다 |
| 워크시트 HTML 파일 | 등록한 그 파일을 인쇄 창으로 띄웁니다 |
| 아무것도 없음 | **책 레벨에 맞는 A4 1장을 자동으로 만듭니다** |

자동 생성본은 학원의 북리포트 워크시트 규격(A4 세로 1장, 영어 전용)을 그대로 따릅니다.
레벨은 시리즈 표기 → AR·Lexile → 분류 순으로 판정하며, 근거가 엇갈리면 낮은 쪽을 택합니다. 쉬운 워크시트가 어려운 것보다 낫기 때문입니다.

| Lv | 이름 | 활동 구성 |
|----|------|-----------|
| 1 | Phonics / Emergent | 단어표 · 사이트워드 · 그리고 쓰기 · 별점 |
| 2 | Early Reader | 인물 짝맞추기 · 새 낱말 · 그리고 쓰기 · 별점 |
| 3 | Beginning Reader | 인물 소개 · 처음·중간·끝 · 좋아한 장면 · 오늘의 낱말 · 별점 |
| 4 | Developing Reader | 인물 감정 · 문제와 해결 · 새 낱말 뜻 · 좋아한 장면 · 교훈 |
| 5 | Fluent / Chapter | 요약 · 인물 분석 · 새 낱말 3개 · 주제와 내 의견 · 추천 |

**도서 등록·수정 창의 워크시트 항목**

- `워크시트 레벨` — 비워두면 책 정보로 자동 판정합니다. 직접 정할 수도 있습니다
- `핵심 단어` — 쉼표로 구분해 넣으면 단어 활동 칸에 들어갑니다. 비우면 학생이 직접 찾아 쓰는 빈칸이 됩니다
- `등장인물` — 쉼표로 구분해 넣으면 인물 활동에 들어갑니다
- `등록된 워크시트 링크` / `워크시트 파일 등록` — 이미 만들어 두신 활동지가 있을 때
- `자동 워크시트 미리보기` — 저장 전에 어떻게 나오는지 확인

> 책에 없는 내용은 지어내지 않습니다. 등록하지 않은 단어나 인물 자리는 학생이 채우는 빈칸으로 나갑니다.

인쇄는 **A4 · 세로 · 배율 100% · 여백 없음 · 배경 그래픽 인쇄 켜기**로 하시면 됩니다.
워크시트 파일은 500KB까지 등록할 수 있고, 그보다 크면 링크로 등록해 주세요.

## 8. 수강료 납부 관리 사용법

1. **설정 · 백업**에서 `기본 월 수강료`, `기본 납부일`, `입금 계좌`를 먼저 등록합니다.
2. 학생마다 금액이 다르면 **학생 명부 → 정보 수정**에서 `월 수강료`·`납부일`을 개별로 넣습니다. 비워두면 학원 기본값이 쓰입니다.
3. 매달 초 **수강료 납부 → [청구서 일괄 생성]**을 누르면 등록생 전체에게 그 달 청구서가 만들어집니다.
   - 이미 청구서가 있는 학생은 건드리지 않으므로, 중간에 등록한 학생이 생겨도 다시 눌러 추가하면 됩니다.
4. 입금이 확인되면 해당 행의 **[납부 처리]** → `전액 납부 입력` → 저장. 분납은 납부 금액만 부분적으로 입력하면 **부분납부**로 잡힙니다.
5. 상태는 자동으로 판정됩니다.

   | 상태 | 조건 |
   |---|---|
   | 청구 | 미납이지만 납부 기한 전 |
   | 미납 N일 | 납부 기한이 지남 (연체 일수 표시) |
   | 부분납부 | 청구액 일부만 입금 |
   | 완납 | 청구액 전액 입금 |
   | 면제 | 청구액을 0원으로 설정 |

6. **[미납 안내 문자]**를 누르면 미납 학생별로 금액·기한·계좌가 채워진 문자 문구가 만들어집니다. 복사하거나 문자 앱으로 바로 보낼 수 있습니다.
7. 납부가 끝난 건은 **[영수증]** 버튼으로 `납부 확인서`를 만들 수 있습니다. 인쇄·PDF 저장은 물론, 링크로 학부모께 보낼 수도 있습니다.

> 현금영수증·카드 결제 자체를 처리하는 기능은 아닙니다. 실제 결제는 기존 방식대로 받고, 이곳에는 **누가 얼마를 언제 냈는지 기록**해 미납을 놓치지 않도록 하는 장부입니다.

## 9. 학부모 공유 링크에 대해

- 링크 안에는 **학생 이름·학년·출결 기록·선생님 코멘트만** 담깁니다. 학생/학부모 연락처는 포함되지 않습니다.
- 링크를 아는 사람은 누구나 열람할 수 있으므로 **해당 학부모님께만** 전달해 주세요. 납부 확인서 링크도 같습니다.
- 리포트는 생성 시점의 기록을 담은 사진 같은 것입니다. 이후 출결이 바뀌어도 이미 보낸 링크는 갱신되지 않으니, 새 기간의 리포트는 새로 만들어 보내면 됩니다.
- 기간이 길면 링크가 길어집니다. 한 달 단위로 끊어 보내시는 것을 권합니다.

## 10. 기술 메모

- 빌드 도구·프레임워크·외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 작성했습니다.
- `assets/js/util.js` (공통 유틸) → `store.js` (데이터) → `ui.js` (공통 UI) → `cloud.js` (Supabase 어댑터) → `sync.js` (동기화 엔진) → `auth-ui.js` (로그인) → `views/*.js` (화면) → `app.js` (해시 라우터) 순으로 읽힙니다.
- 화면 코드는 저장소를 **동기(즉시)로** 읽고 씁니다. 클라우드는 `sync.js`가 뒤에서 주고받으므로, 화면을 추가할 때 동기화를 신경 쓸 필요가 없습니다.
- 모든 레코드에 `updatedAt`이 찍히고, 삭제는 `deleted` 표시로 처리합니다. 그래야 삭제도 다른 기기에 전달됩니다.
- 클라우드 스키마는 [`supabase/schema.sql`](supabase/schema.sql) 한 파일입니다. 표는 `records` 하나뿐입니다.
- 화면을 추가하려면 `assets/js/views/`에 `title() / sub() / render(el)`를 가진 모듈을 만들어 `Views.<이름>`으로 등록하고, `index.html`의 스크립트와 좌측 메뉴에 `#/<이름>` 링크를 넣으면 됩니다.
