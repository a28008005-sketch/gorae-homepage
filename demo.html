📝 사용법 예시

과제 관리:

  1. 시스템 열기 → 좌측 "과제 관리" 클릭
  2. "과제명" 입력 (예: "Chapter 5 읽기")
  3. "반 선택" → "마감일" 설정
  4. "과제 발행" 클릭
  5. "제출 현황" 버튼으로 학생별 제출 확인

상담 일지:

  1. 시스템 열기 → 좌측 "상담 일지" 클릭
  2. 학생 선택 → 날짜 선택
  3. 상담 내용 작성
  4. "학부모에게 공유" 체크
  5. "상담 기록 저장" 클릭
