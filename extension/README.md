# 고래영어 성적 연동 (크롬 확장 프로그램)

본사 성적 목록(`https://englishwhale.com/pt/grade_list.php`)의 표를 읽어
원생관리 **성적 관리 → 시험 기록**으로 보내는 크롬 확장 프로그램입니다. (Manifest V3)

## 설치 (한 번만)

1. 이 `extension` 폴더를 컴퓨터에 둡니다. (받은 압축 파일이면 먼저 풀어 주세요)
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더를 고릅니다.
5. 주소창 오른쪽 퍼즐 아이콘 → **고래영어 성적 연동** 옆 핀을 눌러 고정합니다.

> 폴더를 옮기거나 지우면 확장 프로그램도 사라집니다. 한곳에 두고 쓰세요.
> 파일을 고친 뒤에는 `chrome://extensions` 에서 새로고침(↻)을 눌러야 반영됩니다.

## 쓰는 법

1. 본사 사이트에 로그인해 **성적 목록**을 엽니다.
2. 확장 프로그램 아이콘을 누르면 "이 페이지에서 성적 N건을 찾았습니다" 가 뜹니다.
3. **현재 페이지 데이터 동기화(전송)** 을 누릅니다.
4. 원생관리 창(staff.whalejinju.kr)이 열리고 **성적 가져오기 확인** 창이 뜹니다. [가져오기]를 누르면 저장됩니다.
5. 목록이 여러 쪽이면 쪽마다 2~4를 반복합니다. 같은 기록은 두 번 들어가지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `manifest.json` | 확장 프로그램 설정 (권한 · 어느 화면에서 동작하는지) |
| `content.js` | 본사 성적 목록 화면에서 표를 읽습니다 (머리줄 글자로 칸을 찾음) |
| `popup.html` · `popup.js` | 아이콘을 눌렀을 때 뜨는 창 — 전송 버튼 · 보낼 곳 설정 |
| `background.js` | 실제로 보내는 곳. 팝업은 창을 옮기면 닫혀서 여기서 처리합니다 |
| `bridge.js` | 원생관리 화면 안에서 받은 성적을 화면에 넘겨 줍니다 |

## 보내는 방법 두 가지

### ① 원생관리로 보내기 (기본 · 권장)

서버가 필요 없습니다. 확장 프로그램이 성적을 잠시 맡아 두었다가(`chrome.storage.local`)
원생관리 창을 열어 `bridge.js` 가 `window.postMessage` 로 넘겨 줍니다.
원생관리 화면(`assets/js/views/grades.js`)이 받았다고 대답하면 맡겨 둔 것을 지웁니다.
로그인 화면 때문에 처음에 못 받으면, 로그인 뒤 원생관리 화면을 새로고침할 때 다시 넘겨 줍니다.

같은 컴퓨터 안에서만 오가므로 CORS 문제가 생기지 않고, 저장은 원생관리의 클라우드 동기화를 그대로 탑니다.

### ② 대시보드 API 로 POST

팝업 → 보낼 곳 설정 → **대시보드 API 로 POST** 를 고르고 주소를 넣은 뒤 [저장]을 누릅니다.
이때 크롬이 그 주소로 보내도 되는지 한 번 묻습니다. 허락하면 확장 프로그램의 서비스 워커가 직접 보내므로,
**서버 쪽에 CORS 설정이 없어도** 막히지 않습니다.

보내는 내용 (`Content-Type: application/json`, 토큰을 넣었으면 `Authorization: Bearer <토큰>`):

```json
{
  "source": "englishwhale.com",
  "pageUrl": "https://englishwhale.com/pt/grade_list.php?page=1",
  "scrapedAt": "2026-10-15T05:39:00.000Z",
  "count": 1,
  "rows": [
    {
      "no": "12",
      "name": "강예린",
      "school": "초전초",
      "grade": "6",
      "exam": "2026 가을 정기평가 Level 3",
      "links": [
        { "label": "성적표", "url": "https://englishwhale.com/pt/grade_view.php?idx=12" },
        { "label": "인증서", "url": "https://englishwhale.com/pt/cert_print.php?idx=12" }
      ],
      "registeredAt": "2026-10-10 15:20:11"
    }
  ]
}
```

서버가 200번대로 대답하면 성공, 그 밖이면 팝업에 서버가 보낸 이유가 표시됩니다. 20초 동안 대답이 없으면 멈춥니다.

## 표를 읽는 규칙

- 페이지의 표 가운데 **학생명**과 **시험명** 칸이 있는 표를 고릅니다. 바깥 레이아웃 표 안에 목록 표가 들어 있어도 안쪽을 찾습니다.
- 칸은 순서가 아니라 머리줄 글자로 찾습니다 — 번호 · 학생명 · 학교 · 학년 · 시험명 · 성적표/인증서 · 등록일시.
- 성적표·인증서 링크는 `href` 뿐 아니라 `onclick="window.open('...php?idx=..')"` 같은 팝업 주소도 뽑아 전체 주소로 바꿉니다.
- 이름에 `홍길동(hong12)` 처럼 아이디가 붙어 있으면 이름만 남깁니다.
- `2026.10.09` 같은 날짜는 `2026-10-09` 로 바꿉니다.

**본사 화면을 실제로 열어 확인하지는 못했습니다.** (로그인이 필요한 화면이라)
위 규칙은 비슷한 구조의 시험용 화면으로 확인했습니다. 실제 화면에서 "표를 찾지 못했습니다" 가 뜨면,
성적 목록 화면에서 마우스 오른쪽 → **페이지 소스 보기** 내용을 전달해 주시면 맞춰 고칠 수 있습니다.
그동안은 원생관리의 **표 붙여넣기로 가져오기**로도 같은 기록을 넣을 수 있습니다(링크만 빠짐).

## 개인정보

- 본사 로그인 정보·쿠키는 읽지도 보내지도 않습니다. 화면에 보이는 표 글자와 링크 주소만 옮깁니다.
- 기본 설정에서는 성적이 학원 원생관리 외의 곳으로 나가지 않습니다.
