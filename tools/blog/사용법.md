# 노션 블로그 사용법

노션에 글을 쓰면 홈페이지 블로그에 올라갑니다.
프로그램을 설치할 필요는 없습니다.

---

## 1. 노션 표에 들어가는 칸

| 칸 이름 | 종류 | 하는 일 |
|---|---|---|
| 제목 | 제목 | 글 제목 |
| 상태 | 선택 | `공개`로 두면 홈페이지에 나옵니다. `초안`이면 안 나옵니다 |
| 날짜 | 날짜 | 글 목록에서 최신순으로 정렬하는 기준 |
| 요약 | 텍스트 | 목록 카드에 보이는 한두 줄 |
| 태그 | 다중 선택 | 글 분류 (여러 개 가능) |
| 주소 | 텍스트 | 비워두셔도 됩니다. 비우면 제목으로 자동으로 만듭니다 |

칸 이름이 조금 달라도 알아서 찾습니다.
예를 들어 `제목` 대신 `Title`, `날짜` 대신 `발행일`이라고 지으셔도 됩니다.

**상태 칸이 아예 없으면 모든 글이 공개됩니다.** 초안을 숨기고 싶으시면 꼭 만들어 주세요.

---

## 2. 열쇠(API 키) 넣어두는 곳

`tools/blog/.env.local` 파일에 이렇게 두 줄을 적습니다.

```
NOTION_TOKEN=ntn_여기에_열쇠
NOTION_DATABASE_ID=표주소32자리
```

이 파일은 깃허브에 올라가지 않도록 막아두었습니다. (`.gitignore`에 등록됨)
**열쇠를 다른 사람에게 보여주거나 채팅에 붙여넣지 마세요.**

---

## 3. 블로그 만들기

```
node tools/blog/build.mjs
```

이 한 줄이면 됩니다. 결과는 `site/blog/` 안에 만들어집니다.

- `site/blog/index.html` — 글 목록
- `site/blog/posts/글제목.html` — 글 본문
- `site/blog/images/` — 노션에 넣은 사진

열쇠가 없으면 예시 글 4개로 화면을 만듭니다. 디자인만 먼저 보고 싶을 때 씁니다.

---

## 4. 노션에서 쓸 수 있는 것

문단 · 제목1~3 · 글머리 기호 목록 · 번호 목록 · 인용 · 콜아웃 ·
코드 · 구분선 · 체크박스 · 토글 · 이미지 · 북마크

굵게, 기울임, 취소선, 링크, 인라인 코드 모두 그대로 나옵니다.

> 노션에 올린 사진은 1시간 뒤에 주소가 만료됩니다.
> 그래서 만들 때 사진을 파일로 내려받아 저장합니다. 신경 쓰지 않으셔도 됩니다.

---

## 5. 안 될 때

| 화면에 나오는 말 | 원인 | 할 일 |
|---|---|---|
| 노션 열쇠(API 키)가 맞지 않습니다 | 열쇠가 틀렸거나 만료됨 | `.env.local`의 `NOTION_TOKEN` 다시 확인 |
| 노션 표를 찾지 못했습니다 | 표에 연결을 추가하지 않음 | 표 페이지 → 우측 위 `⋯` → `연결` → 만든 연결 추가 |
| 글이 0개로 나옴 | 상태가 `공개`가 아님 | 노션에서 상태를 `공개`로 변경 |
| 표 주소(ID)가 잘못되었을 수 있습니다 | ID를 잘못 복사함 | 표 주소에서 32자리 부분만 복사 |

---

## 6. 디자인은 어디서 오나요

블로그 화면은 색·폰트를 따로 갖고 있지 않습니다.
`site/index.html`(홈페이지)에서 디자인을 **읽어와서 그대로 씁니다.**

그래서 홈페이지 디자인을 바꾸고 다시 만들면 블로그도 같이 바뀝니다.
반대로 블로그 때문에 홈페이지가 바뀌는 일은 없습니다.
