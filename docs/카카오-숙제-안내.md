# 카카오 채널로 숙제 받기 — 설치 안내

학부모님이 **고래영어학원 카카오 채널 채팅방**에 숙제 녹음·영상·사진을 보내면

1. 챗봇이 바로 **자동 답장**합니다. ("김고래 학생 숙제 잘 받았어요 😊")
2. 파일이 학원 저장소(R2)에 보관되고
3. 원생관리 **대시보드 "오늘 들어온 숙제 · 카톡"** 과 **숙제 영상** 화면에 1분 안에 나타납니다.

학부모님이 보낸 **글 메시지**도 같은 목록에 "카톡 메시지"로 남습니다.

```
학부모 카톡 ─▶ 카카오 챗봇(폴백 블록) ─▶ gorae-homework 워커 /hw/kakao/<열쇠>
                                            ├─ 파일 → R2 sub/ (숙제 영상 목록, 30일 보관)
                                            ├─ 글   → R2 sub/ (카톡 메시지)
                                            └─ 자동 답장
```

추가 비용은 없습니다. 이미 쓰고 있는 숙제 영상 워커(gorae-homework)와 R2 저장소를 그대로 씁니다.

---

## 학부모님이 하실 일

- 처음 한 번만 채팅방에 **`이름 김고래`** 라고 보냅니다. 그다음부터 그 카톡 계정으로 온 숙제는 김고래 학생 것으로 들어갑니다.
- 이름을 보내기 전에 보낸 숙제도, 이름을 보내면 자동으로 그 학생 이름으로 바뀌어 보입니다.
- 형제가 한 휴대폰을 쓰면, 보내기 전에 `이름 김돌고래` 처럼 다시 보내면 바뀝니다.

카카오가 녹음 파일을 챗봇에 넘겨주지 않는 경우에는, 챗봇이 **"숙제 올리기" 버튼**을 답장으로 보냅니다.
버튼을 누르면 지금 쓰는 제출 화면(`/hw`)이 아이 이름이 채워진 채로 열립니다.

## 설치 순서 (원장님)

### 1. 숙제 영상 워커 코드 바꾸기

1. 아래 주소를 크롬에서 열고 **Ctrl+A → Ctrl+C** 로 전부 복사합니다.
   `https://raw.githubusercontent.com/a28008005-sketch/gorae-homepage/main/worker/homework-worker.js`
2. 클라우드플레어 → **Workers & Pages** → **`gorae-homework`** → **Edit code**
   (※ `gorae-staff-gate` 가 아닙니다)
3. 기존 코드를 지우고 붙여넣기 → **Deploy**

### 2. 열쇠 넣기

`gorae-homework` → **Settings → Variables and Secrets → Add**

| 종류 | 이름 | 값 |
|---|---|---|
| Secret | `KAKAO_SKILL_KEY` | `gorae-staff-gate` 에 넣은 것과 같은 값 |

확인: 브라우저에서 `https://staff.whalejinju.kr/hw/kakao/<열쇠>` 를 열어
`카카오 숙제 창구가 열려 있습니다` 가 보이면 됩니다.

### 3. 카카오 스킬 주소 바꾸기

1. 카카오 챗봇 관리자센터 → `고래영어 숙제봇` → **스킬** → `테스트 수신`
2. URL 을 아래로 바꿉니다. (`/api/kakao/test/` → `/hw/kakao/`)
   ```
   https://staff.whalejinju.kr/hw/kakao/<열쇠>
   ```
3. **스킬서버로 전송** → `올바른 스킬 서버 응답입니다` 가 나오면 **저장**
   - 이때 카카오가 보낸 시험 글("발화 내용")이 숙제 영상 목록에 '카톡 메시지'로 한 줄 들어갑니다. 확인 체크해 두시면 됩니다.

### 4. 폴백 블록 · 채널 연결 · 배포

1. **시나리오 → 폴백 블록** → 파라미터 설정의 스킬을 `테스트 수신` 으로, 봇 응답은 **스킬데이터 사용** 하나만 남기고 저장
2. **설정 → 카카오톡 채널 연결** → `고래영어학원` 연결 → 저장
3. **배포**

### 5. 휴대폰으로 확인

원장님 개인 카톡으로 학원 채널에 차례로 보냅니다.

| 보낼 것 | 기대하는 답장 | 원생관리에서 |
|---|---|---|
| `이름 (학생 이름)` | "○○○ 학생으로 등록했어요" | — |
| 음성메시지 / 녹음 파일 | "○○○ 학생 숙제 잘 받았어요" 또는 "숙제 올리기" 버튼 | 숙제 영상에 **카톡 녹음** |
| 사진 | "○○○ 학생 숙제 잘 받았어요" | **카톡 사진** |
| 아무 글 | "메시지 잘 받았어요" + 숙제 올리기 버튼 | **카톡 메시지** |

원생관리 → **대시보드** 위쪽 "오늘 들어온 숙제 · 카톡" 카드와 **숙제 영상** 화면에서 확인합니다.

## 알아 둘 것

- **챗봇이 연결되면 채널로 오는 모든 메시지에 챗봇이 먼저 답합니다.** 학부모님 글은 원생관리 숙제 영상 화면에
  '카톡 메시지'로 남지만, 카카오 채널 관리자센터의 1:1 채팅에서 예전처럼 직접 답장할 수 있는지는
  아직 확인하지 못했습니다. 연결한 뒤 관리자센터 채팅 목록에 메시지가 보이는지 꼭 확인해 주세요.
- **카카오가 음성메시지를 챗봇에 넘겨주는지는 아직 확인되지 않았습니다.** 넘겨주지 않으면 학부모님은 "숙제 올리기"
  버튼으로 올리게 됩니다. 어느 쪽이든 같은 목록에 모입니다.
- 파일과 메시지는 **30일 뒤 자동 삭제**됩니다 (기존 숙제 영상과 같은 규칙). 이름 등록 기록(`kakao/users/`)은 지워지지 않습니다.
- 한 번에 받을 수 있는 파일은 95MB 까지입니다. 더 큰 영상은 "숙제 올리기" 버튼(최대 1GB)으로 올리게 됩니다.
- 카카오 사용자 번호는 그대로 저장하지 않고, 알아볼 수 없게 줄인 값만 씁니다.
