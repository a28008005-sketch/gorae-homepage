# 단어학습앱 연동 안내

만들고 계신 단어학습앱의 결과를 원생관리 홈페이지로 보내는 방법입니다.
앱이 어떤 기술로 만들어졌는지와 무관하게, **아래 형식만 맞추면** 학생별 기록이 쌓입니다.

---

## 1. 학생을 무엇으로 알아보나

두 가지 중 하나를 보내면 됩니다.

| 방법 | 값 | 설명 |
|---|---|---|
| **학생 코드** (권장) | `A3F9` | 홈페이지의 **단어 학습 → 학생 코드**에서 확인·발급. 이름이 겹치거나 바뀌어도 정확합니다 |
| 학생 이름 | `김서준` | 명부의 이름과 **정확히** 같아야 합니다 |

학생 코드는 [학생 코드] 화면에서 **[코드 없는 학생에게 코드 만들기]**를 누르면 한 번에 발급되고,
**[코드 목록 CSV]**로 내려받아 앱에 넣으시면 됩니다.

---

## 2. 보내는 형식

### JSON (권장)

```json
{
  "type": "gorae-vocab",
  "version": 1,
  "sessions": [
    {
      "studentCode": "A3F9",
      "date": "2026-09-03",
      "setName": "Unit 3 단어",
      "total": 20,
      "correct": 18,
      "durationSec": 240,
      "sessionId": "app-20260903-0012"
    }
  ]
}
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `studentCode` 또는 `studentName` | ✅ | 학생 지목 |
| `date` | | `YYYY-MM-DD`. 없으면 가져오는 날짜로 들어갑니다 |
| `setName` | | 단어장·범위 이름. 없으면 "단어 학습" |
| `total` | ✅ | 푼 문항 수 |
| `correct` | ✅ | 맞힌 문항 수 |
| `durationSec` | | 걸린 시간(초) |
| `sessionId` | | **중복 방지 열쇠.** 같은 값이 다시 들어오면 새로 쌓지 않고 덮어씁니다 |

> `sessionId`를 꼭 넣어 주세요. 앱이 같은 결과를 두 번 보내도 기록이 중복되지 않습니다.

### CSV

첫 줄은 열 이름입니다. 순서는 상관없고, 한글·영문 모두 알아봅니다.

```csv
학생코드,날짜,단어장,총문항,정답,학습시간,세션ID
A3F9,2026-09-03,Unit 3 단어,20,18,240,app-20260903-0012
BQWQ,2026-09-03,Unit 3 단어,20,15,310,app-20260903-0013
```

쓸 수 있는 열 이름: `학생코드/code` `학생이름/name` `날짜/date` `단어장/set` `총문항/total` `정답/correct` `학습시간/duration` `세션ID/sessionId`

---

## 3. 보내는 세 가지 방법

### 방법 A — 링크로 자동 전송 (앱에서 쓰기 좋음)

JSON을 **URL-safe base64**로 만들어 다음 주소를 열면, 미리보기와 함께 가져오기 화면이 뜹니다.

```
https://<홈페이지 주소>/#/import?d=<base64 JSON>
```

자바스크립트 예시:

```js
const payload = {
  type: 'gorae-vocab',
  version: 1,
  sessions: [{ studentCode: 'A3F9', date: '2026-09-03', setName: 'Unit 3 단어',
               total: 20, correct: 18, durationSec: 240, sessionId: 'app-20260903-0012' }]
};

const b64 = btoa(unescape(encodeURIComponent(JSON.stringify(payload))))
  .replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');

window.open('https://a28008005-sketch.github.io/gorae-homepage/#/import?d=' + b64);
```

한 번에 너무 많이 보내면 링크가 길어져 잘릴 수 있습니다. **한 번에 50건 이하**로 나눠 보내세요.

### 방법 B — 파일 내보내기

앱에서 `.json` 또는 `.csv`로 저장한 뒤,
**단어 학습 → [기록 가져오기] → [파일 선택]**으로 넣습니다.

### 방법 C — 붙여넣기

**단어 학습 → [기록 가져오기]** 창에 그대로 붙여넣습니다. 급할 때 가장 빠릅니다.

---

## 4. 가져온 뒤

- 학생별 정답률, 학습 횟수, 학습한 단어 수, 학습 시간이 **단어 학습** 화면에 쌓입니다.
- 학생 상세 화면과 반별 비교에도 함께 나옵니다.
- 클라우드를 연결해 두셨다면 다른 선생님 기기에도 자동으로 전달됩니다.
- 학생을 못 찾은 줄은 가져오지 않고 따로 보여드립니다. 코드나 이름을 확인해 주세요.

---

## 5. 더 깊은 연동이 필요하시면

지금은 **앱 → 홈페이지** 한 방향으로 기록을 받는 구조입니다.
아래처럼 더 붙이려면 앱의 구조(어떤 언어·플랫폼으로 만드셨는지, 서버가 있는지)를 알려주세요.

- 홈페이지의 학생 명부·반 정보를 앱이 **읽어가기**
- 숙제로 낸 단어 범위를 앱이 자동으로 **받아가기**
- 앱이 서버에 직접 저장하고 홈페이지가 **실시간으로 읽기** (클라우드 연결 시 같은 데이터베이스 사용)
