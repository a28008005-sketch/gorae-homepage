# 태블릿 등하원 출결

학원 입구 태블릿에서 아이가 **학부모 휴대폰 번호 뒤 4자리**를 누르면 등원·하원이 기록되고,
원생관리 **[출결 · 일일학습]** 화면에 15초 안에 나타납니다.

## 처음 한 번 설정 (태블릿에서)

1. 태블릿 크롬(또는 삼성 인터넷)으로 `https://staff.whalejinju.kr/checkin.html` 을 엽니다.
2. 원생관리 비밀번호 → 학원 계정(이메일·비밀번호) 순서로 로그인합니다. 한 번 로그인하면 계속 유지됩니다.
3. 브라우저 메뉴 → **홈 화면에 추가** 를 누르면 '고래 출결' 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다.
4. 아이들이 다른 화면으로 나가지 않도록 안드로이드 **앱 고정(화면 고정)** 기능을 켜 두는 것을 권합니다.

## 아이가 누르는 순서

1. 번호 4자리 입력 → 이름이 뜨면 눌러서 확인 (형제자매는 이름을 골라 누름)
2. 처음 누르면 **등원** — 자동으로 '출석' 처리되고 등원 시각이 찍힙니다.
3. 집에 갈 때 다시 누르면 **하원할까요?** → [하원하기]
   - 등원하고 10분 안에 다시 누르면 하원으로 처리하지 않고 "이미 등원했어요"라고 알려줍니다.

## 알아둘 것

- 번호는 학생 명부의 **학부모 연락처** 뒤 4자리입니다. 연락처가 비어 있는 학생은 찾을 수 없습니다.
- **등록생**만 찾습니다. 대기·휴원·퇴원생은 뜨지 않습니다.
- 인터넷이 잠깐 끊겨도 태블릿에 저장해 두었다가 연결되면 올립니다.
- 오른쪽 아래 상태 글자를 **2초간 길게 누르면** 동기화 상태 창(지금 동기화·로그아웃)이 열립니다.
