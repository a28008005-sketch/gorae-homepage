# 태블릿 등하원 출결

학원 입구 태블릿에서 아이가 **학부모 휴대폰 번호 뒤 4자리**를 누르면 등원·하원이 기록되고,
원생관리 **[출결 · 일일학습]** 화면에 15초 안에 나타납니다.

## 처음 한 번 설정 (태블릿에서)

1. 태블릿 크롬(또는 삼성 인터넷)으로 `https://staff.whalejinju.kr/checkin.html` 을 엽니다.
2. 원생관리 비밀번호 → 학원 계정(이메일·비밀번호) 순서로 로그인합니다. 한 번 로그인하면 계속 유지됩니다.
3. 브라우저 메뉴 → **홈 화면에 추가** 를 누르면 '고래 출결' 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다.
4. 아이들이 다른 화면으로 나가지 않도록 안드로이드 **앱 고정(화면 고정)** 기능을 켜 두는 것을 권합니다.

## 아이가 누르는 순서

1. 번호 4자리 입력 → 이름이 뜨면 눌러서 확인 (형제자매는 이름을 골라 누름)
2. 처음 누르면 **등원** — 자동으로 '출석' 처리되고 등원 시각이 찍힙니다.
3. 집에 갈 때 다시 누르면 **하원할까요?** → [하원하기]
   - 등원하고 50분 안에 다시 누르면 하원으로 처리하지 않고 "이미 등원했어요"라고 알려줍니다.
4. 하원을 **안 누르고 간 아이**는 등원 **90분 뒤**에 자동으로 하원 처리됩니다.
   - 하원 시각은 '등원 시각 + 90분'으로 찍히고, 출결 화면에 `하원 16:30(자동)` 처럼 보입니다.
   - 자동 하원은 카톡을 보내지 않습니다.
   - 분은 **설정 · 백업 → 등하원 카톡 알림 → 자동 하원** 에서 바꿀 수 있습니다 (0 이면 끔).
   - 태블릿이나 원생관리 화면 중 하나가 켜져 있으면 처리되고, 둘 다 꺼져 있었다면 다음에 켤 때 채워집니다.

## 알아둘 것

- 번호는 학생 명부의 **학부모 연락처** 뒤 4자리입니다. 연락처가 비어 있는 학생은 찾을 수 없습니다.
- **등록생**만 찾습니다. 대기·휴원·퇴원생은 뜨지 않습니다.
- 인터넷이 잠깐 끊겨도 태블릿에 저장해 두었다가 연결되면 올립니다.
- 오른쪽 아래 상태 글자를 **2초간 길게 누르면** 동기화 상태 창(지금 동기화·로그아웃)이 열립니다.

---

## 카톡 알림 — 등원·하원하면 학부모님께 알림톡

아이가 태블릿에서 **등원**이나 **하원**을 누르면 학생 명부의 **학부모 연락처**로 카카오 알림톡이 갑니다.
연락처 칸에 `010-1111-2222, 010-3333-4444` 처럼 두 번호를 적으면 두 분 모두에게 갑니다(최대 3개).
알림톡을 못 받는 번호에는 같은 내용이 문자로 대신 갑니다.

발송은 **솔라피(solapi.com)** 를 거칩니다. 카카오 알림톡은 학원이 직접 보낼 수 없고, 이런 발송 대행사를 거쳐야 합니다.
요금은 알림톡 한 건에 10원대, 문자로 대신 갈 때는 문자 요금입니다 (정확한 값은 솔라피 요금표 확인).

### 처음 한 번 준비 (원장님)

1. **카카오톡 채널 만들기** — center-pf.kakao.com 에서 '고래영어' 채널을 만들고 **비즈니스 채널 인증**을 받습니다 (사업자등록증 필요).
2. **솔라피 가입** — solapi.com 가입 → 충전 → **발신번호 등록** (학원 대표번호 010-3803-8335 등, 통신서비스 이용증명원 필요).
3. **솔라피에 카카오 채널 연동** — 솔라피 → 카카오 알림톡 → 채널 연동. 연동하면 **pfId**(`KA01PF…`)가 나옵니다.
4. **알림톡 템플릿 2개 심사 신청** — 솔라피 → 알림톡 템플릿 → 새 템플릿. 아래 문구를 그대로 쓰시길 권합니다.
   `#{학생명}`, `#{시각}` 두 칸 이름은 **바꾸면 안 됩니다** (워커가 이 이름으로 채웁니다). 나머지 글은 바꿔도 됩니다.

   **등원**
   ```
   [고래영어] 등원 알림
   #{학생명} 학생이 #{시각}에 학원에 도착했습니다.
   ```
   **하원**
   ```
   [고래영어] 하원 알림
   #{학생명} 학생이 #{시각}에 수업을 마치고 하원했습니다.
   ```
   심사는 보통 1~3 영업일 걸립니다. 승인되면 템플릿마다 **템플릿 ID**(`KA01TP…`)가 생깁니다.
5. **솔라피 API 열쇠 만들기** — 솔라피 → 개발/연동 → API Key 관리 → 새 API Key. **API Key** 와 **API Secret** 이 나옵니다.

### 워커에 값 넣기

클라우드플레어 → Workers & Pages → **gorae-staff-gate** → Settings → Variables and Secrets 에서 아래 6개를 넣고 저장합니다.
(`worker/worker.js` 를 새 버전으로 붙여 넣고 Deploy 한 뒤에 하세요.)

| 이름 | 종류 | 값 |
|---|---|---|
| `SOLAPI_API_KEY` | Secret | 솔라피 API Key |
| `SOLAPI_API_SECRET` | Secret | 솔라피 API Secret |
| `SOLAPI_SENDER` | Text | 솔라피에 등록한 발신번호 (예: `010-3803-8335`) |
| `KAKAO_PFID` | Text | 카카오 채널 pfId (`KA01PF…`) |
| `KAKAO_TPL_IN` | Text | 등원 템플릿 ID |
| `KAKAO_TPL_OUT` | Text | 하원 템플릿 ID |

### 켜기

1. `https://staff.whalejinju.kr` → **설정 · 백업 → 등하원 카톡 알림**
2. 상자에 **발송 준비 완료** 가 보이는지 확인합니다. 빠진 값이 있으면 그 이름이 나옵니다.
3. 원장님 번호를 넣고 **[등원 문구로 보내기]** → 휴대폰에 '테스트' 학생 카톡이 오는지 봅니다.
4. **등원 알림 보내기 / 하원 알림 보내기** 를 켭니다. 켜는 즉시 태블릿에도 반영됩니다(15초 안).

### 쓰면서 알아둘 것

- 태블릿 완료 화면에 노란 **"부모님께 카톡으로 알려 드렸어요"** 가 보이면 보낸 것입니다.
- **출결 · 일일학습** 화면 학생 이름 아래에 `카톡 등원 보냄` / `카톡 하원 실패` 처럼 결과가 남습니다. 실패에 마우스를 올리면 이유가 보입니다.
- 선생님이 출결 화면에서 [출석]을 누르는 것으로는 **보내지 않습니다.** 아이가 태블릿에서 찍을 때만 갑니다.
- 등원 직후(50분 안) 다시 눌러도 하원으로 처리하지 않으므로 하원 카톡도 가지 않습니다.
- 태블릿 인터넷이 끊기면 알림을 담아 두었다가 연결되면 보냅니다. **30분이 넘으면** 늦은 알림이라 보내지 않고 '실패'로 남깁니다.
- 같은 기록으로 두 번 요청이 가도 학부모님께는 한 번만 갑니다.
