## 2. 어떻게 굴러가나

### 저장

기본은 **브라우저 localStorage**(`gorae-academy-v1`). 선생님이 여러 명이면 설정에서 **Supabase 클라우드**를 연결합니다.

```
화면(동기 읽기·쓰기) → Store → localStorage
                         ↓ onRecordChange
                       Sync → Cloud → Supabase records 표
```

- 화면은 지금까지처럼 동기로 동작합니다. 동기화는 `sync.js` 가 뒤에서 처리합니다.
- 내 변경: 대기열에 모아 800ms 뒤 전송. 오프라인이면 쌓아뒀다가 연결되면 보냅니다.
- 남의 변경: 15초마다 받아 병합하고 화면을 다시 그립니다.
- 충돌: 나중에 저장된 쪽이 남습니다(서버 시각 기준).
- 삭제: 물리 삭제가 아니라 `deleted: true` 표시. 그래야 삭제가 전파됩니다.

Supabase 쪽 표는 `supabase/schema.sql` 하나이고, 설치 절차는 `docs/서버형-설치안내.md` 에 있습니다.

### 워크시트

책을 빌려줄 때 독후활동지가 함께 나옵니다.

1. 책에 **워크시트 링크**가 등록돼 있으면 그 링크를 엽니다
2. **HTML 파일**이 등록돼 있으면 그 파일을 띄웁니다
3. 없으면 **책 레벨에 맞는 A4 1장을 자동 생성**합니다

레벨은 시리즈 표기 → AR/Lexile → 분류 순으로 판정하고, 엇갈리면 낮은 쪽을 택합니다.
형식은 `book-report-worksheet` 스킬의 규격을 그대로 옮겼습니다.

| 결정 | 이유 |

| 프레임워크·빌드 없음 | 원장님이 파일을 직접 열어 쓸 수 있어야 하고, 배포가 GitHub Pages 뿐입니다 |

| anon 키만 허용, service_role 거부 | 정적 사이트에 전권 키를 두면 안 됩니다. 입력 단계에서 막아 두었습니다 |
| 좌석 배치 삭제 | 반(클래스)이 생기면서 좌석이 관리 단위로서 의미를 잃었습니다. **저장된 좌석 값은 지우지 않았습니다** |
| 순회 점검 → 수업 태도 | 하루에 여러 번 순회하는 대신 그날 출결 줄에서 한 번에 기록하는 쪽이 실제 운영에 맞았습니다. 기존 기록은 자동 이관됩니다 |

## 5-1. 화면 색과 아이콘 (2026-09-16 개편)

밝은 파랑(`#1a7fd4`) 중심이던 색을 로고의 짙은 남색 기준으로 낮추고,
강조색을 황동색(`--brass`)으로 바꿨습니다. 색 이름은 `assets/css/style.css` 의 `:root` 에 있습니다.

이모지(📊 🧒 ✅ …)는 기기마다 모양이 달라 화면이 들쭉날쭉해 보였습니다.
`assets/js/icons.js` 의 선 아이콘으로 모두 바꿨습니다.

- HTML 안에서는 `<i data-icon="students"></i>` — 화면이 뜰 때 자동으로 채워집니다
- JS 안에서는 `Icon.svg('students', 18)`
- `UI.emptyBox(글, '아이콘이름')` 도 아이콘 이름을 받습니다

대시보드에 새로 들어온 **미니 캘린더·업무 상세 계획 달력**은 규칙(CSS)이 없어 화면이
흐트러져 있었고, 위쪽 미니 달력은 내용이 채워지지 않아 빈 칸이었습니다.
`style.css` 끝에 `캘린더` 구역을 넣고 `#mini-calendar` 를 `buildCalendar()` 에 연결했습니다.
달력 칸의 이모지 표시(📝📖👥)는 색으로 구분하는 작은 점으로 바꿨습니다
(황동=숙제 마감, 초록=도서 반납, 파랑=수업 예정).

수업 태도 이름에서도 이모지를 뺐습니다(`🟢 집중` → `집중`).
이미 저장된 기록은 `Store.migrateAttitudes()` 가 한 번 돌며 새 이름으로 옮깁니다.
**되돌리실 때 이 이관 코드를 함께 지우면 예전 기록이 통계에서 빠집니다.**

## 8. 배포가 아직 반영되지 않는 문제 (확인 필요)

**GitHub Pages 가 `main` 이 아니라 다른 브랜치를 내보내고 있습니다.**

마지막 Pages 빌드는 2026-09-04, 브랜치 `claude/whale-english-academy-site-04c6vl`(`0a2d367`)
입니다. 그 뒤 `main` 에 올린 커밋들(대시보드 개편, 색·아이콘 개편)에서는
Pages 빌드가 한 번도 돌지 않았습니다.

즉 지금 `staff.whalejinju.kr` 에는 **9월 4일 화면**이 떠 있습니다.

고치는 법 — GitHub 저장소에서 한 번만 바꾸면 됩니다.

1. 저장소 → **Settings → Pages**
2. **Build and deployment → Source** 가 `Deploy from a branch` 인지 확인
3. **Branch** 를 `claude/whale-english-academy-site-04c6vl` → **`main`** / `/ (root)` 로 변경
4. Save → 1~2분 뒤 Actions 탭에 `pages build and deployment` 가 도는지 확인

바꾸신 뒤 `staff.whalejinju.kr` 을 새로고침하면 새 화면이 나와야 합니다.
