# 카카오 채널 숙제 수집 — 1단계 테스트

본 개발에 들어가기 전에 **한 가지만** 확인합니다.

> 학생이 카카오 채널(`pf.kakao.com/_xexaZcn`)로 녹음 파일을 보내면,
> 챗봇이 그 파일을 우리 홈페이지로 넘겨주는가?

넘겨주면 카카오로 바로 받는 방식(방법 A)으로, 안 넘겨주면 제출 링크 방식(방법 B)으로 만듭니다.

이 테스트 창구는 **아무것도 저장하지 않습니다.** 받은 내용을 정리해서 카톡 답장으로 돌려줄 뿐입니다.

---

## 1. 워커에 열쇠 넣고 새 코드 올리기 (5분)

카카오 서버는 선생님 비밀번호를 모르기 때문에, 주소 끝에 붙이는 **비밀 열쇠**로 문을 엽니다.

1. 클라우드플레어 대시보드 → **Workers & Pages** → `gorae-staff-gate`
2. **Edit code** → 저장소의 `worker/worker.js` **전체를 붙여넣기** → **Deploy**
3. **Settings → Variables and Secrets → Add**
   - 종류: **Secret**
   - 이름: `KAKAO_SKILL_KEY`
   - 값: 영문·숫자 20자 이상 아무 문자열 (예: `gorae` 뒤에 무작위 글자)
4. 저장

확인: 브라우저 주소창에 아래 주소를 넣었을 때
`"카카오 테스트 창구가 열려 있습니다"` 라는 글이 보이면 성공입니다.

```
https://staff.whalejinju.kr/api/kakao/test/<넣은 열쇠>
```

---

## 2. 카카오 오픈빌더에 봇 만들기 (10~20분)

카카오 화면 메뉴 이름은 바뀔 수 있습니다. 비슷한 이름을 찾아 눌러 주세요.

1. <https://i.kakao.com/openbuilder/> 에 학원 채널 관리자 카카오 계정으로 로그인
2. **봇 만들기 → 카카오톡 챗봇** → 이름 `고래영어 숙제봇`
   - 사용 신청이나 비즈니스 인증을 요구하면 안내대로 진행합니다. 승인까지 며칠 걸릴 수 있습니다.
3. 왼쪽 **스킬** → **생성**
   - 스킬 이름: `테스트 수신`
   - URL: `https://staff.whalejinju.kr/api/kakao/test/<넣은 열쇠>`
   - 저장
4. 왼쪽 **시나리오** → **폴백 블록** 열기
   - **파라미터 설정 → 스킬 선택**에서 `테스트 수신` 선택
   - 봇 응답을 **스킬데이터 사용**으로 설정
   - 저장
5. 오른쪽 위 **배포** → 배포
6. **설정 → 카카오톡 채널 연결**에서 `고래영어학원` 채널 연결

> 폴백 블록은 "어떤 블록에도 안 걸린 모든 메시지"를 받는 곳입니다.
> 그래서 사진·파일·녹음처럼 미리 정할 수 없는 메시지를 확인하기에 알맞습니다.

---

## 3. 실제로 보내 보기

**원장님 개인 카톡**으로 학원 채널에 들어가 아래를 하나씩 보내 주세요.

| 순서 | 보낼 것 | 확인할 것 |
|---|---|---|
| ① | `안녕하세요` (글) | 답장이 오는지. 여기서 답장이 안 오면 2단계 설정 문제입니다 |
| ② | 사진 1장 | `찾은 파일 주소`가 나오는지 |
| ③ | **카톡 음성메시지** (마이크 버튼 눌러 녹음) | ★ 제일 중요 |
| ④ | **녹음 앱에서 만든 파일** (+ → 파일 → m4a 등) | ★ 제일 중요 |

잘 되면 이런 답장이 옵니다.

```
[고래영어 테스트 수신 ✅]
보낸 말: http://talk.kakaocdn.net/....m4a
블록: 폴백 블록
보낸 사람 번호: 3f9a1c… · 채널키 있음 · 봇키 있음

찾은 파일 주소 1개
· userRequest.utterance [소리 m4a]
  http://talk.kakaocdn.net/....
```

---

## 4. 결과를 알려 주세요

③과 ④ 각각 **어떤 답장이 왔는지 캡처**해서 보내 주시면 됩니다.

| 결과 | 뜻 | 다음 단계 |
|---|---|---|
| `찾은 파일 주소`에 `소리`가 뜸 | 녹음이 넘어옴 | **방법 A** — 카카오로 바로 받기 |
| `파일 주소는 들어오지 않았습니다` | 도착은 하지만 파일이 안 넘어옴 | **방법 B** — 제출 링크 |
| 답장이 아예 없음 (①은 되는데) | 챗봇이 그 종류를 받지 않음 | **방법 B** — 제출 링크 |

더 자세히 보고 싶으면 클라우드플레어 → `gorae-staff-gate` → **Logs → Begin log stream**
을 켜 놓고 보내 보세요. `[kakao-test]` 로 시작하는 줄에 카카오가 보낸 원본이 그대로 찍힙니다.

## "올바르지 않은 스킬 서버 응답입니다" 가 뜰 때

스킬 화면의 **스킬서버로 전송**을 눌렀을 때 이 오류가 나오면, 카카오가 보낸 요청이
워커까지 오지 못했거나 워커가 카카오 형식이 아닌 답을 준 것입니다. 어느 쪽인지 로그로 가립니다.

1. 클라우드플레어 → `gorae-staff-gate` → **Logs**(또는 Observability) → **Begin log stream** / **Live** 켜기
2. 그 창을 띄워 둔 채로 카카오 스킬 화면에서 **스킬서버로 전송** 다시 누르기
3. 로그에 무엇이 찍히는지 보기

| 로그 | 뜻 | 할 일 |
|---|---|---|
| `[kakao-test] POST 도착 · 열쇠 틀림` | 주소의 열쇠가 다름 | 스킬 URL 을 브라우저에서 성공했던 주소로 다시 붙여넣기 |
| `[kakao-test] POST 도착 · 열쇠 맞음` 뒤에 `{"intent"…` | 워커는 정상 응답 | 로그 화면을 캡처해 보내 주세요 |
| **아무것도 안 찍힘** | 워커 앞(클라우드플레어 보안)에서 막힘 | 아래 보안 설정 확인 |

**아무것도 안 찍힐 때 — 클라우드플레어 보안 확인**

클라우드플레어의 **봇 차단 기능**은 사람이 아닌 서버가 보내는 요청(카카오 서버 포함)을 막을 수 있습니다.

1. 클라우드플레어 → 도메인 `whalejinju.kr` 선택
2. **Security → Events**(보안 이벤트)에서 방금 시각에 막힌 요청이 있는지 보기
3. 있으면 **Security → Bots**(또는 Security → Settings)에서 **Bot Fight Mode** 를 끄기
4. 카카오 스킬 화면에서 **스킬서버로 전송** 다시 누르기

## 알아 둘 것

- **챗봇을 채널에 연결하면, 그 채널로 온 메시지에 챗봇이 먼저 답합니다.**
  테스트 기간에 학부모님 메시지에도 테스트 답장이 나갈 수 있으니,
  학부모님이 적게 보내는 시간(밤)에 테스트하고 끝나면 **채널 연결을 해제**해 주세요.
- 채널 관리자센터의 1:1 채팅(직접 답장)과 챗봇을 함께 쓰는 설정은 카카오 화면에서
  다시 확인해야 합니다. 이 부분은 아직 확인하지 못했습니다.
- 테스트 창구는 받은 내용을 저장하지 않습니다. 보낸 사람 번호도 답장에는 앞 6자리만 보입니다.
- 테스트가 끝나면 이 창구는 본 기능으로 바꾸거나 지웁니다.
