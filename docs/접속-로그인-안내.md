# 접속 주소와 로그인 안내

원장님이 실제로 누르시는 순서대로 적었습니다.

---

## 1. 주소 정리

| 주소 | 누가 열어보나 | 비밀번호 |
|---|---|---|
| **https://whalejinju.kr** | 누구나 (학원 홍보 사이트) | 없음 |
| **https://staff.whalejinju.kr** | 원장님과 선생님 (원생관리) | **있음** |
| **https://staff.whalejinju.kr/p/#/report?d=...** | 학부모 (학습 리포트) | 없음 |

원생관리 대시보드는 `staff.whalejinju.kr` 하나만 기억하시면 됩니다.
휴대폰에서는 이 주소를 열고 **홈 화면에 추가**해 두시면 앱처럼 쓰실 수 있습니다.

- 아이폰: 사파리 → 공유 → 홈 화면에 추가
- 안드로이드: 크롬 → 메뉴 → 앱 설치

## 2. 로그인은 두 겹입니다

헷갈리기 쉬운 부분이라 먼저 말씀드립니다. 잠금이 **두 개**이고, 목적이 다릅니다.

### 첫 번째 — 학원 비밀번호 (문 잠금)

`staff.whalejinju.kr` 에 들어오면 가장 먼저 뜨는 화면입니다.
**학원 비밀번호 하나**를 넣으면 그 기기는 **30일 동안** 다시 묻지 않습니다.

주소만 알면 아무나 화면을 열어보는 것을 막는 자물쇠입니다.
선생님이 몇 분이든 같은 비밀번호를 쓰십니다.

이 잠금은 클라우드플레어 워커가 담당합니다. 설치는 `worker/README.md` 에 있습니다.

### 두 번째 — 선생님 계정 (기록 공유용)

문을 열고 들어온 다음, **여러 기기에서 기록을 함께 보려면** 선생님 계정으로 한 번 더
로그인합니다. 이메일과 비밀번호를 넣는 화면입니다.

- 계정은 **원장님이 만들어 드립니다** (설정 · 백업 → 클라우드 연결 → Supabase)
- 비밀번호를 잊으신 선생님은 원장님께 재설정을 요청하시면 됩니다
- 혼자만 쓰실 거라면 이 단계는 건너뛰어도 됩니다.
  로그인 화면에서 **[이 기기에만 저장하는 모드로 쓰기]** 를 누르면 됩니다

정리하면 이렇습니다.

```
staff.whalejinju.kr 열기
      ↓
학원 비밀번호 한 번  ← 아무나 못 들어오게 (30일 유지)
      ↓
선생님 계정 로그인    ← 다른 선생님 기록까지 함께 보려면 (안 해도 됨)
      ↓
대시보드
```

## 3. 비밀번호 정하기와 바꾸기

학원 비밀번호는 저장소 안에 들어 있지 않습니다. 클라우드플레어에만 넣습니다.

**처음 정할 때 / 바꿀 때**

1. 클라우드플레어 대시보드 → **Workers & Pages** → `gorae-staff-gate`
2. **Settings → Variables and Secrets**
3. `STAFF_PASSWORD` 를 찾아 **Edit** → 새 비밀번호를 넣고 저장

또는 컴퓨터에서 한 줄로:

```bash
cd worker
npx wrangler secret put STAFF_PASSWORD
```

바꾸고 나면 **이미 로그인해 둔 기기는 그대로 유지**됩니다.
모든 기기를 한 번에 로그아웃시키고 싶으시면 `SESSION_SECRET` 도 함께 바꾸시면 됩니다.

**비밀번호 정하실 때**

- 8자 이상, 학원 이름과 숫자를 섞으신 정도면 충분합니다 (예: `gorae-chojeon-2026`)
- 선생님들께는 문자나 메모로 전달하시고, 퇴사 시 한 번 바꿔 주세요

## 4. 학부모에게 보내는 링크

학습 리포트와 납부확인서 링크는 **비밀번호 없이** 열려야 합니다.
그래서 주소 앞에 `/p/` 가 붙습니다.

앱이 이 주소로 링크를 만들게 하려면 한 번만 설정해 주시면 됩니다.

1. **설정 · 백업** 화면을 엽니다
2. **학부모 공개 링크 주소** 칸에 이렇게 넣습니다

   ```
   https://staff.whalejinju.kr/p/
   ```

3. 저장합니다

이후 **학부모 공유** 화면에서 만드는 링크는 모두 비밀번호 없이 열립니다.
칸을 비워 두면 지금 보고 있는 주소를 그대로 쓰는데, 그러면 학부모에게도
비밀번호 화면이 떠 버립니다. **잠금을 켜셨다면 이 칸은 꼭 채워 주세요.**
