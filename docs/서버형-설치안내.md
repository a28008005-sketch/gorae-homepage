# 여러 선생님이 함께 쓰기 — 설치 안내

선생님들이 각자 휴대폰·노트북에서 **같은 명부와 출결**을 보도록 만드는 설정입니다.
서버를 직접 운영하지 않고, Supabase라는 무료 서비스를 저장소로 씁니다.

전체 30분쯤 걸리며, 프로그램 설치는 없습니다. **원장님이 한 번만** 하시면 됩니다.

---

## 1단계 · Supabase 프로젝트 만들기

1. https://supabase.com 접속 → `Start your project` → GitHub 또는 이메일로 가입
2. `New project` 클릭
   - **Name**: `gorae-academy` (아무 이름이나 괜찮습니다)
   - **Database Password**: 아무 비밀번호나 만들고 **따로 적어 두세요**
   - **Region**: `Northeast Asia (Seoul)` 선택 — 한국에서 가장 빠릅니다
3. `Create new project` → 2분 정도 기다립니다

> 무료 요금제로 충분합니다. 학생 100명 · 출결 수만 건 정도는 무료 범위 안입니다.

---

## 2단계 · 표 만들기 (SQL 한 번 실행)

1. 왼쪽 메뉴에서 **SQL Editor** 클릭 → `New query`
2. 이 저장소의 [`supabase/schema.sql`](../supabase/schema.sql) 파일 내용을 **전부 복사**해 붙여넣기
3. 오른쪽 아래 **Run** 클릭 → `Success` 가 나오면 끝입니다

---

## 3단계 · 선생님 계정 만들기

1. 왼쪽 메뉴 **Authentication → Users** → `Add user` → `Create new user`
2. 선생님 이메일과 임시 비밀번호를 넣고, **Auto Confirm User 를 켠 채로** 만듭니다
   - 이걸 켜야 이메일 인증 절차 없이 바로 로그인할 수 있습니다
3. 함께 쓰실 선생님 수만큼 반복합니다. 원장님 계정도 이렇게 만드세요.

> 비밀번호를 잊은 선생님이 생기면, 같은 화면에서 해당 사용자의 `⋯` → `Reset password` 로 바꿔 주시면 됩니다.

---

## 4단계 · 홈페이지에 연결하기

1. Supabase 왼쪽 메뉴 **Project Settings → API** 로 들어갑니다
2. 두 가지를 복사해 둡니다
   - **Project URL** — `https://xxxxxxxx.supabase.co`
   - **anon public** 키 — `eyJhbGciOi...` 로 시작하는 긴 문자열
3. 원생관리 홈페이지를 열고 **설정 · 백업 → 여러 기기에서 함께 쓰기** 로 갑니다
4. 위에서 복사한 두 값을 붙여넣고 **[클라우드 연결]** 클릭
5. 로그인 화면이 나오면 3단계에서 만든 계정으로 로그인합니다

> ⚠️ **`service_role` 키는 절대 넣지 마세요.** 그 키는 모든 권한을 가지므로 브라우저에 두면 안 됩니다.
> 홈페이지도 그 키는 거부하도록 막아 두었습니다. 반드시 **anon public** 키를 쓰세요.

---

## 5단계 · 쓰던 기록 옮기기

지금까지 이 기기에 쌓인 명부·출결·수강료 기록을 그대로 클라우드로 올립니다.

1. 로그인한 상태에서 **설정 · 백업 → 여러 기기에서 함께 쓰기 → [전체 올리기]**
2. "○○건을 올렸습니다" 가 뜨면 완료입니다

다른 컴퓨터에서 쓰던 기록을 합치려면:

1. 그 컴퓨터에서 **설정 · 백업 → [백업 파일 내보내기]** 로 JSON 파일을 받습니다
2. 클라우드에 로그인한 기기에서 **[백업 파일 불러오기]** 로 그 파일을 넣습니다
   - 불러오면 모든 기록에 새 수정 시각이 찍혀 자동으로 클라우드에 올라갑니다

---

## 6단계 · 다른 선생님 기기 설정

선생님들은 각자 기기에서 홈페이지를 열고, **4단계만** 하시면 됩니다.
(프로젝트 URL + anon 키 입력 → 본인 계정으로 로그인)

---

## 평소 사용법

- 기록은 **입력하는 즉시 그 기기에 저장**되고, 1초쯤 뒤 자동으로 클라우드에 올라갑니다.
- 다른 선생님이 입력한 내용은 **15초마다** 자동으로 내려옵니다. 화면을 다시 열거나 상태 칩의 `지금 동기화` 를 눌러 즉시 받아올 수도 있습니다.
- 오른쪽 위 **☁️ 상태 칩**으로 연결 상태를 확인합니다.
  - `클라우드 연결됨` — 정상
  - `오프라인 · 대기중 (3)` — 인터넷이 끊겨 3건이 밀려 있음. 연결되면 자동으로 올라갑니다.
- 인터넷이 끊겨도 **계속 입력할 수 있습니다.** 끊긴 동안의 입력은 기기에 쌓였다가 연결되면 올라갑니다.

## 같은 기록을 두 선생님이 동시에 고치면

**나중에 저장한 쪽이 남습니다.** (기록 한 줄 단위, 서버 시각 기준)

출결 체크나 순회 기록처럼 선생님마다 담당이 나뉘는 입력에서는 문제가 되지 않습니다.
다만 같은 학생의 정보를 두 분이 동시에 편집하면 나중 것만 남으니, 학생 정보 수정은 한 분이 맡는 편이 안전합니다.

## 자주 묻는 것

**Q. 학부모 공유 링크와 납부 확인서도 로그인이 필요한가요?**
아니요. 그 두 화면은 링크만 있으면 로그인 없이 열립니다.

**Q. 클라우드를 쓰면 이 기기에는 기록이 안 남나요?**
남습니다. 클라우드는 사본이고, 각 기기에도 그대로 저장됩니다. 그래서 인터넷 없이도 열람·입력이 됩니다.

**Q. 백업은 계속 해야 하나요?**
클라우드를 쓰면 기기 한 대가 고장 나도 기록은 남습니다. 그래도 학기마다 한 번씩 **백업 파일 내보내기**로 파일을 받아 두시길 권합니다.

**Q. 무료 요금제가 끊기면요?**
Supabase 무료 프로젝트는 **일주일 이상 아무도 접속하지 않으면 일시 정지**될 수 있습니다. 학원에서 매일 쓰신다면 해당되지 않습니다. 방학처럼 오래 쉬실 때는 한 번씩 열어 주시거나, 방학 전에 백업 파일을 받아 두세요.
